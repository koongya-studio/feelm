# 평점 이력이 없는 영화의 콘텐츠 예측

Jira: [S15P21E106-338](https://ssafy.atlassian.net/browse/S15P21E106-338)

**사용자의 대중성 반응을 넣을 이유는 발견했지만 ALS 대체 성능을 입증한 것은 아니다.**
FM·GBT를 후속 비교 후보로 유지하고 최종 서비스 모델·전환 K·추천 정책은 보류한다.
2026-09-10 완료한 로컬 학습·독립 검토 결과다. 연구 완료와 MR 리뷰·병합은 구분한다.

## 질문과 비교 조건

ALS가 학습한 영화의 다른 사용자 과거 평점은 참고 ALS에 남겼다. 같은 목표 영화의 평점은
콘텐츠 모델의 모든 학습 경로에서 가렸다. 콘텐츠 모델이 평점 이력 없이 실제 별점을 얼마나
맞히는지, ALS의 예측에 얼마나 가까운지를 별도로 비교했다. ALS를 정답으로 학습하지 않았다.

같은 평가 사용자·입력·미래 관측을 사용한다. 입력은 ALS 지원 W 영화이며 목표만 콘텐츠에
미지원이다. ALS가 모르는 영화만 입력한 사용자나 모든 실제 신작의 검증은 아니다.

| 누적 조건 | 추가한 정보 | 사용 특징 수 |
|---|---|---:|
| BASE | 영화 속성 + 입력 별점과 장르·인물 등의 반응 | 168 |
| SUPPORT | 근거 편수·수축 보정 묶음 | 200 |
| CROWD_ITEM | TMDB 평점·평가 수·인기도와 결측 표시 | 206 |
| CROWD_RESPONSE | 사용자 입력의 대중성 분포·별점 반응 | 230 |

각 조건을 FM·공유 리지·Spark GBT로 학습해 총 12개를 비교했다. 특정 배우·감독의 효과를
각각 입증한 실험은 아니다. BASE에도 개인 반응이 들어 있으므로 추가 효과는 **대중성 반응**이다.
공통 저장 특징은 398열이고 각 조건은 위 표의 열만 선택한다. 실제 별점은 0.5 단위를 유지했다.

![조건별 오차와 선호 순서](assets/cold-item-content/cold-item-content/comparison.png)

## 결론

| 확인한 질문 | 결과 |
|---|---|
| 대중성 반응을 더하면 좋은가? | FM K10 선호 순서가 60.4→66.5%. 차이 +6.16%p, 사전 보정 구간 +0.14~+14.26%p로 이 조건에서 개선 확인. |
| K30도 확정적인가? | FM 62.3→70.8%였지만 보정 구간에 0이 포함돼 미확정. |
| 근거 편수 보정은 필수인가? | 시험한 SUPPORT는 리지 K30 MSE를 0.8162→0.8427로 악화시켰다. 현재 보정 묶음을 필수 채택할 근거가 없다. |
| ALS를 넘어섰는가? | ALS 대비 사전 비교 48개 모두 차이 미확정. 동급이라는 뜻도 아니다. |

FM K10의 순서 개선은 비교 가능한 **71명·1,664쌍**의 한 조건이다. 사용자마다 먼저 점수를
계산했으며 영화 쌍을 독립 사용자처럼 세지 않았다. 보정 구간 하한이 0에 가까워 제한적 근거다.
인접 조건 대조 36개와 ALS 대조 48개를 각각 별도로 다중비교 보정했다.
FM·GBT 직접 우열과 SUPPORT 없이 반응만 추가한 조합은 사전 검정 대상이 아니었다.

| K10 오차: 117명·461관측·312영화 | BASE | SUPPORT | CROWD_ITEM | CROWD_RESPONSE |
|---|---:|---:|---:|---:|
| FM MSE ↓ | 0.7742 | 0.7774 | 0.7518 | 0.7117 |
| 공유 리지 MSE ↓ | 0.8296 | 0.8430 | 0.8082 | 0.8546 |
| GBT MSE ↓ | 0.7762 | 0.7939 | 0.7704 | 0.7340 |

참고 ALS K10 MSE는 0.7211, 실제 별점 순서는 69.4%였다. 기본값으로 대체한 ALS가 아니다.
MSE는 예측을 0.5~5로 제한하고, 순서와 ALS 재현도는 반올림하지 않은 원래 예측을 쓴다.
실제 별점 동점 쌍은 제외하고 예측 동점은 절반으로 센다. K30 오차/순서 평가자는 113/68명이다.
서로 다른 K는 대상이 달라 단순 차이를 입력량의 효과로 해석하지 않는다.

FM K10의 ALS 순서 일치율은 대중 지표 조건 67.2%에서 반응 조건 76.2%로 움직였다.
이는 77명·2,151쌍의 기술통계다. **ALS를 닮는 능력과 실제 별점을 맞히는 능력은 별개다.**
전체 카탈로그 Top-N 적중률이나 ALS 순위를 증류한 학습의 결과가 아니다.

## 검증과 한계

콘텐츠 학습은 39,859명·4,997,069평점이다. 학습 목표 82.43%는 K0이며,
입력이 있는 목표는 878,107건이다. K10 평가자 중 과거 30편 미만은 2명뿐이다.
적게 평가하는 사용자에게도 같은 효과가 있다고 일반화하지 않는다.

MovieLens의 기존 개발 관측과 2026년 TMDB 수치를 사용했다. 대중 지표는 당시 이미 알던
정보가 아니며 순수 영화 내용만 쓰는 조건도 아니다. 단일 영화 보류 분할이고 사용자 bootstrap은
그 영화 집합에 조건부다. 2026년 한국 서비스 효과·인과관계·최적 수렴을 보증하지 않는다.
8개 분류를 전제로 삼지 않았다. 줄거리·Wikipedia는 이 실험 특징에 들어가지 않았다.

원본 정답 482건, 사용자 지표 15,054행, 집계·구간 708개와 모델별 예측을 독립 검산했다.
학습 함수 시간 합은 95.4분, 최대 컨테이너 메모리는 10.59GiB다. Spark local[4]의
실제 학습 기록이며 전체 작업 시간·서비스 지연·EC2 또는 다중 노드 성능은 아니다.
