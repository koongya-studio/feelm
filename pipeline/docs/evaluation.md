# 어떤 문제를 평가했는가

이번 근거는 이미 평가한 영화의 일부 입력 O를 보여 주고 별도 평가 영화 E에서
선호를 얼마나 복원하는지 본 결과다. 사용자가 평가하지 않은 영화는 UNKNOWN이다.
미평가를 싫어요나 실패로 바꾸지 않는다.

| 구분 | 의미 |
| --- | --- |
| 학습 사용자 | ALS Factor·콘텐츠 prior 학습에 사용 |
| 평가 사용자 | 해당 연구의 학습에서 제외 |
| O | 평가 사용자에게서 모델에 공개한 입력 별점 |
| E | O와 분리한 채점 대상. 정답 정보는 채점 때만 사용 |
| Q | 평가 사용자의 전체 별점 분포에서 계산한 동점 midrank |

Q=(더 낮은 별점 수+동점 수/2)/전체 평가 수이다. 상위 2편의 평균 Q와 최소 Q를
함께 보고 HARM20(Q≤0.2) 비율도 확인했다. 동점 때문에 HARM20은 영화 수의
정확한 하위 20%와 다를 수 있다. 별점 예측 오차나 Recall@500과는 다른 질문이다.

ALS 조건부 분석은 E 안에서 모델별 상위 두 편을 선택했다. 따라서 실제 서비스가
내놓은 미평가 영화의 품질을 측정했다고 설명하면 안 된다. REC030의 본인 입력 대
타인 입력 비교는 인기 편향만으로는 설명되지 않는 개인화 신호를 확인한다.

MovieLens의 rating timestamp는 시청 시점이 아니다. 미래 시청 예측 실험이라고
부르지 않는다. seed를 바꾸어 평가자가 반복 등장하면 독립 관측으로 합산하지 않는다.

최종 K, 온보딩 영화 선정, 취향/발견 정책은 별도 설계가 필요하다. 향후 실험에서는
정책에 맞는 후보가 존재하는지와, 실제 선택된 영화에 채점 가능한 정보가 있는지를
먼저 확인하고 품질을 해석해야 한다.
