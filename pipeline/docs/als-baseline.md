# 원별점 ALS를 연구 비교 기준으로 유지

원점수 ALS는 이미 평가된 영화를 비교하는 조건에서 기존 고정 ALS+콘텐츠 RRF60보다
유리했다. 입력 30개에서는 MovieLens 학습 사용자 인기 기준선보다도 세 지표가 좋았다.
실제 별점은 **0.5~5.0, 0.5 간격**으로 보관하고 ALS에도 원점수를 사용한다.

| 입력 30개, REC032 조건부 상위 2편 | 평균 Q×100 ↑ | 최소 Q×100 ↑ | HARM20 ↓ |
| --- | ---: | ---: | ---: |
| 원별점 ALS | 68.13 | 57.40 | 8.99% |
| MovieLens 학습 평점의 보정 평균 P0 | 64.34 | 52.17 | 14.82% |
| 기존 동일 가중 RRF60 ALS+콘텐츠 | 61.25 | 48.95 | 16.42% |

근거: [ALS 집계](assets/als-only-metrics.json), [독립 검토](assets/als-only-review.json).
P0는 MovieLens 학습 평점의 보정 평균 별점이다. 영화별 평점 합을 S, 평가 수를 n,
학습 전체 평균을 μ라고 하면 `P0=(S+50×μ)/(n+50)`으로 계산했다.
TMDB popularity나 단순 평가 건수 순위가 아니다.

학습 46,376명과 평가 2,180명은 분리했다. 사용자 구성을 바꾼 세 회차에서도 입력
30개의 세 지표 개선 방향을 확인했다. 실제 학습 21,108,386행 감사에서 해당 회차 평가
사용자 유입은 0행이었다. 고유 평가자는 3,819명이므로 총 6,540회분을 독립 사용자로
세지 않는다. [재분할 집계](assets/user-resplits-metrics.json),
[감사](assets/user-resplits-review.json).

## 입력 표현 비교

| REC035 입력 30개 | 평균 Q×100 ↑ | 최소 Q×100 ↑ | HARM20 ↓ |
| --- | ---: | ---: | ---: |
| A: 원별점 ALS | 68.1 | 57.4 | 9.0% |
| B: 시험한 상대값 ALS | 61.2 | 47.9 | 16.6% |
| C: 이진 입력을 추정 별점으로 환산, 원별점 ALS | 67.7 | 56.7 | 9.1% |

B의 고정 설계는 불리했다. C−A의 9개 비교 구간에는 0이 들어갔으며, 동등성이
입증된 것은 아니다. C는 실제 LIKE/DISLIKE 설문이 아니라 평점 상대값 부호로 만든
대리 입력을 사용했다. 따라서 실제 온보딩 효과를 입증하지 않는다.

C의 LIKE=4.2712316165, DISLIKE=2.7984425098은 학습 사용자만으로 추정한 계산값이다.
실제 감상 별점으로 저장하거나 서비스 상수로 확정하지 않는다.
[입력 비교 집계](assets/input-comparison-metrics.json),
[독립 검토](assets/input-comparison-review.json).

## 구현 연결과 한계

- [팀 학습 함수](../spark/batch/train/training.py)는 raw explicit ALS를 구현한다.
  [설정 기록](../configs/als-baseline.json)의 rank32/reg0.1/10회/seed42는 연구 기준이다.
- [계산 참고 코드](../spark/batch/evaluation/reference.py)의 Fold-in은
  `(YᵀY + λmI)p = Yᵀr`이다. m은 Factor가 존재해 계산에 사용한 입력 수다.
  ID 정렬·누락 Factor 처리는 호출자의 책임이다. 평가용 전체 이력을 넣으면 안 된다.
- 기존 [팀 모델 계약](../contracts/als-model-artifacts.md)은 그대로 따른다.
  연구 item-only NPZ는 그 계약을 만족하지 않는다.
- 이 결과는 최종 K=30, 모든 Hybrid의 실패, 학습 수렴, 실제 미평가 영화 추천 품질을
  증명하지 않는다. 현재 팀의 사용자별 시간순 분할과 연구의 사용자 분리는 서로 다르다.
