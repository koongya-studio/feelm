## 개인·파티 원순위와 필수 제외

TASTE/PARTY 모두 별도 공개근거 품질 필터 없이 GBT 원점수 또는 확정 파티 집계로 줄 세운다.
DISCOVERY의 기존 그룹 공급 의미와 **현재 모드별 제외 계약**은 유지한다.
개인 TASTE Backend 최종 제외는 미존재·평가·관심없음이며 감상·OTT 클릭을 제외나 재가중에 쓰지 않는다.
DISCOVERY Consumer는 확정 감상을 추가로 선제외하지만 TASTE 원시 후보의 의미는 바꾸지 않는다.
근거는 [streaming-contract](../../../docs/api/streaming-contract.md)의2.1절과 Candidate v6다.
PARTY Backend는 구성원의 평가·관심없음·확정 감상을 제외한다.
연구 fixture의 감상-only 제외를 개인 TASTE의 기존 서비스 계약으로 간주하지 않는다.
TASTE 확대 적용은742/627에서 계약 합의가 필요하다. API·DB·Redis/Kafka 계약은 여기서 바꾸지 않는다.

파티는 공통 후보를 같은 GBT/특징 변환으로 각 구성원에 대해 점수화한다. 구성원별 midrank
백분위를 동등 가중 평균하고 최저fit·분산·영화ID로 동점을 푼다. doubled midrank의 정수
합/최솟값/분산분자로 입력 순서에 따른 부동소수점 순위 차이를 막는다. K0 구성원은 평균에
가짜0점으로 넣지 않고 제외 목록만 반영한다. 전원K0은483, 후보 부족은 실제 가용 수를 반환한다.
구체적인 운영 집계/캐시·스냅샷 계약 구현과 개인/파티 원점수 일치 검증은747의 일이다.

실제 취향322평가, 10명의 모든2인45+3인120조합을 품질 필터 없이 검산했다.

| 검산 | 결과 |

| 개인 Top100 합집합 | 전체 공통 후보의 공동 Top100에서 총878슬롯 누락 |

있으므로 실제 파티 만족도나 절대 품질 보증으로 해석하지 않는다.

## 테스트 입력 정정과 검증 한계

영어 제목6행은 테스트가 넣은 입력이라는 사용자 확인을 반영했다. 실제 취향은322개이며
328개 `all-titles` 실행은 입력 수용 시험일 뿐 실제 취향 검증이 아니다. 기존 비교 HTML은
6개가 취향에서 빠졌지만 본영화 제외에는 남아 있던 과거 검토본이다. 원본은 보존했다.
최종 파티 검산은 테스트의 본영화 제외까지 풀고6개 사용자–후보 점수만 복원했다.
기존303개 대조 점수는 오차0이며 모델·기존 점수는 바꾸지 않았다.
**영어 제목 전체를 운영에서 막는 정책이 아니다.**

- K1/3/10/30/100/8,518 구조, 전체 입력·실평점 우선·관심없음 취소·감상 제외를 검증했다.
  최대K 원순위에는 근거 부족 후보6편이 있었다. 임의K 지원은 모든K 품질 보증이 아니다.
- 예약 MovieLens는2,999명·미래 사용자–영화 관측96,571행, NDCG10 유효2,994명이다.
  GBT0.6681, MAX0.6207, TMDB평점0.6753으로 모든 기준선보다 우수하지는 않다.
  연구 전체 미사용 홀드아웃·전체 카탈로그 회수율·한국 사용자 만족도로 표현하지 않는다.
- ALS+콘텐츠 대조는10명36누적상태·Top100이다. 9/14 번들·현재 Consumer·기본50:50을 썼으며
  동일 최신 특징 스냅샷이나 활성 서버 설정을 대조한 것은 아니다.
  ALS 역순 점수 불변36상태 FAIL, Top100 순서9상태 변화/집합 변화0을 그대로 기록했다.
- 기존 FEELM 개발 입력 재사용이며 새 실제 만족도·파티 반응, Linux·실서버·배포는 검증하지 않았다.
