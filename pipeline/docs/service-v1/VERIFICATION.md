검토에서 과거 감사와 현재 게시 시점, 절대경로 치환 설명, 합성33개 테스트의 실제 범위를
정정했다. 외부48개 수신용 `--artifact-root`와 원본104개까지 확인하는 `--source-root`도 분리했다.
누락·바이트/해시 변조·상위/절대 경로 이탈을 각각 거부했고 반복 입력의 결과가 같았다.
외부 목록은 원문 없이 검사할 수 있음을 별도 경로 검증으로 확인했다. 이때 파일 검사의 mock을
실제 데이터 검산으로 세지 않았으며, 실제 외부48개 해시는 전달자 로컬에서 따로 확인했다.

게시 목록은119개 파일(목록 JSON 자체 제외), 이관 출처104개, 외부파일48개다.
JSON6개 설정값은 원본과 동일하고, 역사 원문의 개행·링크·머신경로·끝 공백 변환은 출처에 기록했다.

## MR !206 독립 검증 후 출처 수정

추가 독립 세션에서 발견한 P3 한 건은 발표자 노트의 개인 PC 절대 경로였다.
6장 노트를 게시된 자료 12개의 고정 GitLab 커밋 링크로 교체했다. 신뢰구간·고유 영화 수의
원본 근거 CSV2개를 추가했으며, 실험 수치와 해석 한계 문구는 유지했다.

- PPTX 구조·레이아웃·6장 재가져오기·렌더링 검사 통과. 표5개, 차트2개와 내장 workbook 유지.
- 원본 대비 노트 XML6개만 변경되고 다른 ZIP 항목은 바이트가 동일하다.
- GitLab 고정 커밋에서 출처12개의 존재를 확인했다. 게시본/원본 해시와 파일 수를 갱신했다.
- 게시 검증기에 PPTX XML/관계 속성의 Windows·UNC·file URI 검사를 추가했다.
- 분리 재검증에서 문단 경계로 경로가 가려지는 누락을 보완했다. 오류 입력10개 거부,
  정상 HTTPS1개 허용, 원본 PPTX 거부·수정본 통과를 당시 확인했다.
- 이번 수정은 게시 출처와 검증 보완이며, 생산 코드·추천 설정·모델 학습 변경은 없다.

## 추가 독립 재검증의 P3 두 건 보완

`9748653`을 대상으로 한 새 세션에서 정상 HTTPS의 run 분할 오탐과 Markdown 문서를
이미지로 삽입한 문제를 발견했다. 이전 출처·실험 수치 검증은 통과했고 P1/P2는 없었다.

- XML의 문단 안 run을 연결하되 문단·줄바꿈 경계는 유지한다. 개별 run 조각의 `s:/`를
  드라이브 경로로 오인하거나 별개 문단을 합쳐 `C:/`를 만드는 검사를 수정했다.
- 문단 밖 텍스트·tail, 확장 메타데이터와 관계 속성의 경로 검사는 유지했다. 표준 라이브러리 회귀 테스트10개를
  추가했으며 HTTPS 및 Windows/UNC/file URI의 여러 run 분할 지점을 검사한다.
- 역사 문서3곳의 미포함 그림을 일반 안내 링크로 수정하고 게시본 해시·변환 기록을 갱신했다.
  원본 해시, PPTX, CSV, 모델·추천 설정은 변경하지 않았다.
- 회귀 테스트10개와 분리 재검증97개 입력(기존67·추가 경계28·확장 메타데이터2)이 모두 통과했다.
  실제 PPTX에서 노트 문자와 다른 ZIP 항목을 유지하고 HTTPS run만 분리한 사례도 통과했다.
  추가 검증에서 발견한 확장 메타데이터 검사 누락도 같은 재현 입력으로 수정 확인했다.

실행: [재현 안내](REPRODUCTION.md)의 게시 검사와 회귀/합성 테스트 명령. 기존 모델 학습/평가를 다시 실행하지 않았다.
새 KOBIS245 모델, 원230열 전체 재구성, 실모델 Spark/Consumer parity, 그룹 export,
pgvector 검색 S01~S08, v1 정책 replay, Kafka/Redis/API/EC2/HDFS 통합은 **미실행**이다.
과거 검토 PASS는 각 당시 연구 파일의 정확성 검토이며 새 서비스의 품질 보증이 아니다.
