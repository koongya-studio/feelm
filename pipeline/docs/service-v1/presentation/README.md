# 발표 설명 순서

최신 기준은 아래 설명과 [v1](../README.md)이다. 함께 있는 6장 PPTX는 결합 비교군·KOBIS 확대 수집·상세 유사 영화 추가 전의 기본 구성 참고본이다. 최신 수치·최종 설계의 유일한 자료로 쓰지 않는다.

1. **문제:** MovieLens는 과거 사용자 평점, TMDB는 현재 글로벌 영화 정보·투표, KOBIS는 한국 극장 발권이다. 수집 시점·이용자·단위가 달라 MovieLens를 잘 맞추는 점수만으로2026 한국 서비스 적합성을 결정할 수 없다.
2. **확인:** [TMDB/KOBIS 분석](../data-analysis/tmdb-kobis-v1-20260913/REPORT.md)의 평가 수·관객 수·영화 간 평균평점 분산과 MovieLens 영화 내 평점 표준편차를 구분한다. 과거 Top200 탐색 표본의 그래프이며 확대자료의 새 상관계수가 아니다.
3. **비교:** [같은 ALS 지원 목표](../MODEL-COMPARISON.md)에서 GBT MSE는 ALS보다0.020476(2.95%) 높고 NDCG@2 점추정은0.009517 높았다. ALS 미지원624행은 ALS가 계산하지 못했고 GBT/FM은 계산했다. 통계적 우위를 확정하지 않는다.
4. **선택:** 영화 정보와 사용자 반응으로 미지원 영화까지 계산하는 성격과 개발 지표를 함께 보고 GBT를 v1 기본으로 정했다. FM·ALS 및 ALS 결합은 비교군으로 남긴다. GBT의 실제 한국 만족도 우위가 입증된 것은 아니다.
5. **동작:** 맞춤은 배치500→현재 입력500 재정렬, 발견은8×128 중최대10그룹×10편, 반환은맞춤2+발견1. 상세 유사 영화는 기존GKT131/pgvector/공용캐시로 기본10편을 제공하도록 설계했다.
6. **남은 검증:** KOBIS72,700개 영화·연도 기록은 수집했지만 확대자료의 확정출처연결은0개.245열 새모델·API·인덱스·실서비스 검증은 남아 있다. K10·각 후보 상한은 운영 기본값이며 실험 최적값이라고 하지 않는다.
