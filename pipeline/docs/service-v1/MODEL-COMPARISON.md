# ALS·FM·GBT의 같은 분모 비교

상태: **LEGACY COMPARISON EVIDENCE**. 과거에는 GBT를 v1 기본 후보로 두었으나 현재 GBT/FM
노출 모델은 미확정이며, 625의 봉인 평가와 사용자 평가를 거쳐 결정한다. 아래 수치는 그 결정을
대신하지 않는다. 현재 기준은 [현재 개발 방향](CURRENT-DIRECTION.md)을 따른다.

아래는 과거 hybrid345, cap10, H_POSITIVE 개발 결과다. FM/GBT는 seed339/344/345의 지표 평균이며
단일 배포모델이나 예측 ensemble의 점수로 부르지 않는다. 현재 한국 사용자·KOBIS245·맞춤2+발견1
새 정책을 평가한 수치가 아니다. 이미 열어본 개발 표본이다.

## 채택 및 비교군

- GBT: 과거 v1 기본 후보. 현재230 연구 모델, legacy245 비교안, 새 모델별 profile의 준비 상태를 분리한다.
- FM·ALS: 같은 요청·입력·후보에서 shadow 비교. 외부 평가 수/관객 수를 ALS의 실제 별점으로 넣지 않는다.
- ALS+GBT·ALS+FM: [전환/혼합7경로](HYBRID-COMPARISONS.md)를 구현해 추가 이득과 지원률을 분리한다. 자동으로 노출을 바꾸지 않는다.
- 한국영화 고정 보너스나 TMDB/KOBIS 원값 단순 max는 채택하지 않았다. 출처별 자격과 별도 반응 특징을 사용한다.
