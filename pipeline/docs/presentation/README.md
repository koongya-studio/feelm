# 발표용 핵심 설명

이 파일은 팀 발표에 옮길 수 있는 짧은 원고다. 전체 개인 실험 일지는 포함하지 않는다.

1. **왜 원별점 ALS를 유지하는가.** 학습에 참여하지 않은 평가 사용자에게서 일부 별점을
   받아 비교했다. 입력 30개 조건에서 ALS는 MovieLens 학습 평점의 보정 평균 기준선보다 평균·최소
   선호도가 높고 낮은 선호 영화 비율이 작았다. 사용자 구성을 바꾸어도 방향을 확인했다.
2. **상대값은 어디에 유효했는가.** 시험한 상대값 ALS는 원점수보다 불리했다.
   반면 콘텐츠 가중치에서는 사용자 안에서의 상대 선호로 본인 취향을 구분하는 신호를
   확인했다. ALS 학습값과 콘텐츠 가중치를 같은 규칙으로 바꿀 필요는 없다.
3. **콘텐츠 근거가 별도로 있는가.** TMDB 구조 콘텐츠는 확인용 사용자 3,345명에서
   타인 입력보다 본인 입력을 썼을 때 HARM20이 8.63%p 낮았다.
4. **무엇을 아직 말할 수 없는가.** 이미 평가된 영화의 별점을 가린 평가다.
   실제 신작 추천 품질·온보딩 편의성·최종 K·8개 군집 방식은 아직 확정하지 않았다.

사용할 표는 [ALS](../als-baseline.md), [콘텐츠](../structured-content.md)에 있다.
입력 표현 비교 그림: [원본 검증 그림](../assets/input-comparison.png).
Q는 실제 별점이 아니며 그림의 HARM20은 낮을수록 좋다.
