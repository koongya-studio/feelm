# 4. 시연 시나리오

배포 서비스 <https://j15e106.p.ssafy.io/app/>를 **데스크톱 브라우저(가로 1280px 이상)** 에서 시연하는 순서다.
각 단계는 화면, 조작(클릭 위치), 보여줄 점으로 적는다. 버튼 문구는 화면에 보이는 그대로 적었다.

## 4.0 준비

| 준비물 | 내용 |
| --- | --- |
| 시연 계정 A | 평가가 수십 편 쌓여 필름·팝콘·리포트가 채워진 계정. 로그인해 둔다 |
| 시연 계정 B | A와 파티를 만들 계정. 다른 브라우저(또는 시크릿 창)에 로그인해 둔다 |
| 신규 가입용 이메일 | 인증번호를 받을 수 있는 메일함. 가입 시연을 생략하면 필요 없다 |
| 평가할 영화 | A가 아직 평가하지 않은 영화 제목 하나(예: 검색해서 바로 찾을 수 있는 유명작) |

화면 공통 구조: 왼쪽 메뉴에 **취향 필름 · 추천 영화 · 파티팝콘 · 영화 탐색 · MY**, 맨 아래에 **설정**과 계정 메뉴가 있다.
위쪽에 검색창("영화, 감독, 배우로 검색해보세요.")과 오른쪽 끝 **종 모양 알림** 아이콘이 있다.

## 4.1 시연 흐름 요약

| 순서 | 장면 | 화면 | 핵심 메시지 |
| --- | --- | --- | --- |
| 1 | 시작·가입·온보딩 | `/start` → `/signup/email` → `/onboarding/taste` → `/onboarding/ott` | 카드를 끌어 놓는 것만으로 첫 취향이 생긴다 |
| 2 | 취향 필름 | `/film` | 감상 기록이 필름 프레임으로 쌓인다 |
| 3 | 취향 팝콘 | `/film/popcorn` | 취향이 8가지 맛 팝콘으로 보인다 |
| 4 | 오늘의 추천 | `/recommendations` | 취향 맞춤 추천과 취향 발견 추천, 추천 이유(XAI) |
| 5 | 영화 상세·OTT 연결 | `/movies/:id` | 볼 수 있는 OTT로 바로 이동, 유사 영화 |
| 6 | 평가 → 프레임·팝콘 추가 | `/movies/:id/rate` → `/rate/result` | 평가 한 번에 프레임 1개·팝콘 1알 |
| 7 | 영화 탐색 | `/search` | 검색과 장르·개봉연도·OTT 필터 |
| 8 | 파티팝콘 | `/party` → `/party/new` → `/parties/:id/popcorn` → 추천 | 여러 명의 취향을 섞어 함께 볼 영화 추천 |
| 9 | 취향 리포트 | `/my/reports/:id` | 취향 4컷과 캐릭터 카드, 이미지 저장 |
| 10 | MY·OTT 찾기 | `/my` → `/my/settings` → `/otts/recommend` | 내 취향에 맞는 OTT 추천 |

## 4.2 단계별 상세

### 1. 시작 화면과 가입·온보딩

1. 로그아웃 상태에서 `https://j15e106.p.ssafy.io/app/` 접속 → 스플래시 후 **시작 화면**(`/start`).
   가운데 로고 아래 **시작하기** 버튼을 누른다. (이미 계정이 있으면 아래 "이미 계정이 있나요? **로그인**")
2. 가입 방법 화면(`/signup`): **카카오로 시작하기 / 구글로 시작하기**, "또는" 아래 **이메일로 가입하기**를 누른다.
3. 이메일 가입(`/signup/email`): 항목이 위에서부터 하나씩 열린다.
   - 닉네임 입력 → 오른쪽 **중복 확인**
   - 생년월일 → 성별(여성 / 남성 / 선택 안 함)
   - 이메일 입력 → 오른쪽 **인증요청** → 메일로 받은 6자리를 "인증번호 6자리" 칸에 넣고 **확인**
     ("이메일 인증을 마쳤어요." 표시)
   - 비밀번호, 비밀번호 재확인 → 맨 아래 **가입하기**
4. 가입 완료(`/signup/complete`): 편지 애니메이션 뒤 "첫 취향 필름을 만들어볼까요?" → **시작하기**.
5. 취향 초기 설정(`/onboarding/taste`): 영화 카드 10장이 점선 원 둘레에 놓이고 가운데 "나"가 있다.
   - 좋아하는 영화 카드를 **원 안쪽으로 끌어다 놓는다**(가까이 = 좋아요). 바깥에 두면 싫어요, 카드의 ⊖는 "안 봤어요".
   - 아래 **취향 설정 완료 (좋아요 n개 · 싫어요 n개)** 를 누른다.
   - 보여줄 점: 고른 결과가 좋아요 4점·싫어요 2점 평가로 저장되어 바로 추천에 쓰인다.
6. OTT 설정(`/onboarding/ott`): "구독 중인 OTT가 있으신가요?"에서 OTT 타일을 골라 **선택 완료 (n개)**.
7. 온보딩 완료(`/onboarding/complete`): "첫 취향 필름이 감겼어요" → **영화 추천받기**.

> 가입은 메일 인증 때문에 시간이 걸린다. 발표 시간이 짧으면 1~4는 설명으로 넘기고, 온보딩 직전까지 진행한 계정으로 5부터 보여 준다.
> 이후 단계는 준비된 시연 계정 A로 진행한다.

### 2. 취향 필름 (`/film`)

1. 왼쪽 메뉴 **취향 필름**을 누른다. 처음 들어온 계정이면 오른쪽 아래에 "처음 사용 가이드"(6단계)가 뜬다.
   **다음**으로 넘기거나 **건너뛰기**로 닫는다.
2. 화면 위쪽 "나의 취향 필름 / N개의 프레임이 감겼어요" 아래 필름 띠에 평가한 영화 포스터가 프레임으로 이어져 있다.
   오른쪽 위 **‹ ›** 화살표로 필름을 넘긴다.
3. 프레임(포스터)을 누르면 그 영화의 상세 화면으로 간다(5단계에서 다시 보여 주므로 여기서는 넘겨 보기만 한다).
4. 필름 아래 **오늘의 추천** 카드(맞춤 추천 / 취향 확장 배지)를 짚어 준다.
5. 오른쪽 패널: **나의 취향 팝콘**(맛별 감상량·선호도 표), **취향 리포트**(리포트 뽑기), **보셨나요?**(감상 확인하기).

### 3. 취향 팝콘 (`/film/popcorn`)

1. 필름 화면 오른쪽 **나의 취향 팝콘** 패널 머리의 **›** 를 누른다.
2. 팝콘 버킷 그림, "팝콘 N알", "{맛} 쪽으로 기울었어요"가 보인다.
3. 보여줄 점: 맛별 알 수는 **감상량**, ★는 그 맛 영화들에 준 **평균 별점(선호도)** 으로, 두 축이 따로 보인다.
   아래 범례에서 8가지 맛의 이름·설명·개수·평균 별점을 짚어 준다.

### 4. 오늘의 추천 (`/recommendations`)

1. 왼쪽 메뉴 **추천 영화**를 누른다.
2. 두 묶음이 나란히 보인다.
   - 왼쪽 **취향 맞춤 추천**: "좋아한 영화와 가장 가까운 편이에요" (GBT 개인 추천)
   - 오른쪽 **취향 발견 추천**: "기존 취향과 연결되는 새로운 맛이에요" (새로운 맛 발견)
3. 큰 카드의 추천 이유 문장(예: "‘메멘토’을 재미있게 봐서 골랐어요.")을 짚어 **추천 설명(XAI)** 을 보여 준다.
4. 카드 오른쪽 위 **관심없음**을 누르면 카드가 바로 빠진다(추천 제외 피드백). 시연 영화를 잃지 않도록 작은 카드로 한다.
5. 오른쪽 패널 "추천 기준" 태그와 "최근 본 영화"를 짚는다.
6. 큰 카드 아래 **영화 상세 보기**를 누른다.

### 5. 영화 상세와 OTT 연결 (`/movies/:id`)

1. 제목·포스터 옆 **내 별점 남기기**와 **관심없음** 버튼이 있다.
2. "OTT" 구역의 **{OTT}에서 보기** 줄을 보여 준다. 구독 중인 OTT에는 "구독 중" 표시가 붙고 위로 정렬된다.
   누르면 새 탭으로 OTT 페이지가 열리고 감상 기록(`링크 클릭함`)이 남는다. 새 탭은 닫고 돌아온다.
3. 아래로 내려 줄거리, 출연·제작, **이런 영화도 좋아할 거예요**(임베딩 기반 유사 영화), 한줄평을 보여 준다.

### 6. 평가 → 프레임·팝콘 추가

1. 위쪽 검색창에 준비한 영화 제목을 입력하고 결과 포스터를 누른 뒤 오른쪽 패널의 **영화 상세 보기**로 들어간다.
   (또는 필름 화면 오른쪽 위 **본 영화 평가하기** → 검색)
2. **내 별점 남기기**를 누른다 → 평가 화면(`/movies/:id/rate`).
3. "이 영화를 어떻게 평가하시겠어요?" 아래 별 5개에서 별점을 고른다(0.5점 단위).
   "한 줄 감상 남기기 (선택)"에 한줄평을 쓰고, 공개 범위를 **공개**로 둔다.
4. 아래 **평가 완료**를 누른다.
5. 결과 화면(`/rate/result`): 필름이 감기는 애니메이션 뒤 "프레임 1개 · 팝콘 1알이 추가됐어요", "{맛} 맛 +1알",
   "팝콘 버킷 a알 → b알"이 뜬다.
6. **취향 필름 확인**을 눌러 필름 맨 앞에 새 프레임이 붙은 것을 보여 준다.
   보여줄 점: 평가가 Kafka 이벤트로 넘어가 추천 후보가 다시 계산된다(추천 영화 화면을 다시 열면 반영).

### 7. 영화 탐색 (`/search`)

1. 왼쪽 메뉴 **영화 탐색**을 누른다. 검색 홈에 최근 검색어, 급상승, 평점 높은 영화가 있다.
2. 위쪽 검색창에 감독이나 배우 이름을 두 글자 이상 입력하면 바로 결과가 나온다("검색 결과 N").
3. 결과 위 **필터**를 눌러 장르 칩, 개봉연도(2020년대 등), OTT를 고르고 **결과 보기 · N편**을 누른다.
   정렬은 옆 선택 상자(관련도순 / 최신순 / 평점순)로 바꾼다.
4. 포스터를 누르면 오른쪽 패널에 감독·출연진·유사한 작품이 열린다.

### 8. 파티팝콘

1. 왼쪽 메뉴 **파티팝콘**을 누른다(`/party`). 받은 초대, 참여 중인 파티, 지난 파티가 보인다.
2. 오른쪽 위 **파티 만들기** → 인원 선택(`/party/new`)에서 **2인** → **다음**.
3. 파티 만들기(`/party/new/setup`): 파티 이름 입력(예: "금요 심야 상영회") →
   "닉네임으로 친구 찾기"에 계정 B 닉네임 입력 → **검색** → 결과의 **+ 추가** → 아래 **친구 1명과 파티 만들기**.
4. 대기 화면: "친구가 오면 함께 섞어요". 계정 B 브라우저에서 위쪽 **알림**(종) 또는 파티팝콘 화면의
   받은 초대 **수락하기**를 누른다.
5. 계정 A 화면이 "우리의 취향을 모아요" → "취향이 섞이는 중" → "새 팝콘이 완성됐어요"로 넘어가고 추천으로 이동한다.
6. 파티 추천(`/parties/:id/recommendations`): "우리에게 어울리는 N편 / 2명의 취향을 한 통에 담았어요".
   섞인 팝콘 버킷과 추천 목록을 보여 주고, **다음**으로 넘기거나 아래 **다른 영화 추천받기**를 누른다.
   보여줄 점: 한 명만 좋아하는 영화가 아니라 최저 만족도와 편차를 반영한 영화가 위에 온다.
7. 파티 화면(`/parties/:id/popcorn`)에서 "우리의 믹스 팝콘"과 멤버별 팝콘 버킷을 번갈아 보여 준다.

> 파티는 멤버가 모두 참여해야 섞기가 시작된다. 시간을 아끼려면 미리 만들어 둔 파티를 **참여 중인 파티**에서 골라 **파티로 이동**한다.

### 9. 취향 리포트

1. 왼쪽 메뉴 **MY** → "4컷 리포트" 카드를 누른다(`/my/reports`). 리포트 카드를 하나 누른다.
   (새 리포트를 뽑는 장면은 필름 화면 오른쪽 **취향 리포트** 패널의 **리포트 뽑기** → **리포트 보기**)
2. "{연도} {상/하반기} 취향 리포트"의 4컷(장르 · 감독 · 배우 · 캐릭터)이 보인다.
   "각 컷을 눌러 뒷면의 설명을 확인해 보세요" 안내대로 컷을 눌러 뒤집는다.
   **캐릭터 컷 뒷면**에 캐릭터 카드가 있다.
3. 아래 **저장**을 누르면 PNG 이미지 다운로드가 시작된다("다운로드를 시작했어요").

### 10. MY와 나에게 맞는 OTT 찾기

1. 왼쪽 메뉴 **MY**(`/my`): 프로필 카드, 내 취향 키워드, "내 기록" 탭(평가한 영화 / 최근 본 영화 / 추천 기록 / 관심 없음).
2. 왼쪽 아래 **설정** → "나에게 맞는 OTT 찾기" 배너의 **OTT 추천받기**(`/otts/recommend`).
3. **내 OTT 취향 분석하기** → 분석 화면 → 결과(`/otts/recommend/result`): "{닉네임} 님에게 가장 잘 맞는 OTT예요",
   1위 카드의 **상세 보기**로 그 OTT에서 볼 수 있는 추천작을 보여 준다.
4. 마무리로 **취향 필름**으로 돌아와 오늘 평가한 프레임과 늘어난 팝콘을 다시 보여 준다.

## 4.3 시연 중 주의

- **관심없음**(데스크톱 추천 화면)은 확인 없이 바로 빠진다. 시연할 카드를 누르지 않는다.
- 평가는 영화당 한 번만 반영된다. 리허설에서 쓴 영화는 평가를 삭제하거나 다른 영화로 바꾼다.
- OTT 이동은 새 탭으로 열린다. 발표 화면이 새 탭으로 넘어가지 않도록 바로 닫는다.
- 파티 섞기와 추천 재계산은 Kafka·Consumer를 거치므로 몇 초 걸릴 수 있다. 결과가 늦으면 미리 만든 파티로 넘어간다.
- 네트워크가 불안하면 3장 DB 덤프를 복원한 로컬 환경에서 시연 계정(`user13@feelm.test` / `FeelmDemo2026!`)으로 대신한다.
  이때 유사 영화 추천은 임베딩이 없어 비어 있다.
