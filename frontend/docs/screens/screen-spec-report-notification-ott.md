## 3. 화면별 메모

### 리포트의 모양 — 한 칸씩 4컷

**취향 리포트는 세로로 네 칸이 이어진 4컷 사진이다**(사용자 결정 2026-09-13). 장르 · 감독 ·
배우 · 캐릭터가 한 칸에 하나씩 위에서 아래로 이어지고, 띠 아래 여백에 `FEELM · 2026 상반기`를
적는다. 칸은 와이어프레임 칸(190 × 130)의 비율이다. 첫 구현은 두 칸씩 나눈 격자였고 이 결정으로 바꿨다. 와이어프레임 3.4도 좁고 긴 띠
안에 칸 넷을 쌓았다.

3.3 · 3.4 · 7.4가 같은 `components/ReportFourCut`을 쓴다. 띠가 화면의 어두운 블록이다.

### 7.3 취향 리포트 목록

**연도로 나누고 한 해에 상반기 · 하반기 두 칸을 세로로 세워, 칸이 화면 높이를 꽉 채운다**(사용자 결정 2026-09-13). 비율을 고정하지 않고 남은 높이를 연도 묶음이 나눠 갖는다. 작은 화면에서는 칸이 최소 높이(200px)에서 멈추고 스크롤된다.
와이어프레임은 네 칸을 한 격자에 섞고 칸마다 연도를 적었다. 4컷 리포트가 세로로 긴 사진이라
목록의 칸도 세로로 세운다. 연도는 최신이 위, 한 해 안에서는 상반기가 왼쪽이다.

### 3.3 새 취향 리포트 발급

밝은 면의 인화기 배출구에서 4컷이 내려오는 장면이다. 배출구까지 어둡게 그리면 어두운 블록이
둘이 되어 틈 하나로만 그렸다.

### 3.4 · 7.4 취향 리포트 상세

한 컴포넌트(`ReportDetailPage`)가 `from`으로 `저장`의 목적지만 가른다. 맨 위가 4컷이다. 비교의 빼기는 흐리게 쓰고 색으로 가르지 않는다.

### 3.5 공유

Web Share API로 기기 공유 메뉴를 연다. `이미지로 저장`은 API-061로 이미지 카드를 만들고
안내만 한다 — 목업에 실제 이미지가 없다.

### 8.1 알림

읽지 않음은 빨간 점이다(`design-concept.md` 2.2). 시각은 상대 시각이다 — 3.1은 절대 날짜로
정했지만(2026-09-07) 알림은 언제 왔는지가 내용이다. 이틀이 지나면 날짜로 바꾼다.

### EXT-02 분석 중

5.4와 같은 필름 띠 장면이다. 단계 넷은 일정 간격으로 켜고, 모두 켜질 때까지를 최소 노출
시간으로 둔다. 서버 진행과 이어진 값이 아니다.
