# 공개 프로필 한줄평 (S15P21E106-953)

API-087 `/users/{publicId}/reviews`는 선택 인증이다. 프로필은 최근 3개를 조회하고 다음 페이지가 있을 때 전체 보기 버튼을 제공한다. 전체 목록 `/app/users/{publicId}/reviews`는 첫 10개를 표시하고 더 불러오기로 화면을 10개씩 늘린다.

공개 목록은 PUBLIC 평가만 포함한다. 긴 원문은 두 줄로 접고 펼칠 수 있으며 스포일러는 평가 보기 전까지 원문을 렌더하지 않는다. 영화 제목은 상세 화면으로 이동한다. 공개 미리보기의 한줄평 개수는 API-062의 실제 값이다.

더 불러오기 시 이미 표시된 범위도 최신 목록에서 다시 조회하여 개별 비공개 전환·삭제를 반영한다. 요청당 최대 50개, 필요한 화면 길이까지만 조회한다. 목록이 매우 길어지면 재조회 비용이 표시된 항목 수에 비례한다. 전체 페이지 snapshot은 보장하지 않는다. 차단·프로필 비공개·구역 비공개 또는 빈 페이지 전환 시 기존 항목을 폐기한다. 네트워크 실패에서는 기존 목록을 유지하고 재시도한다.
