# Frontend AI 작업 지침

이 문서는 `frontend/**` 작업에 적용한다. 루트 [`AGENTS.md`](../AGENTS.md)의 공통 규칙을 함께 따른다.

## MR 전 Prettier 검사

- 프론트엔드 변경을 포함한 MR을 생성하거나 기존 MR에 수정 커밋을 Push하기 전에 `frontend/`에서 **반드시 `npm run format:check`를 실행하고 통과 여부를 확인한다.**
- 검사 이후 코드, 테스트, CSS 또는 문서를 수정했으면 마지막 수정 후 검사를 다시 실행한다. 이전 실행 결과를 최종 검증 결과로 사용하지 않는다.
- 포맷 오류가 있으면 해당 파일에 `npx prettier --write <파일 경로>`를 적용한 뒤 `npm run format:check`를 다시 실행한다. 작업과 무관한 파일을 일괄 포맷하지 않는다.
- 검사가 실패하거나 실행하지 못한 상태에서는 MR 생성 또는 수정 커밋 Push를 진행하지 않는다. 범위 밖 파일이나 기존 변경 때문에 실패하면 해당 파일과 원인을 사용자에게 알린다. 검사 범위를 임의로 줄여 전체 검사가 통과했다고 보고하지 않는다.
- MR 본문과 완료 보고에 실제 실행한 명령과 결과를 기록한다. 테스트, TypeScript 또는 ESLint 통과는 Prettier 검사 통과를 대신하지 않는다.
