## Production 이미지 수동 검증

빌드 이미지를 `127.0.0.1:18081`에 일시 실행해 다음을 확인했다.

- `/app/`와 SPA 직접 경로 `/app/my/settings`: `200`, 동일 React 진입 문서 제공
- `/app/manifest.webmanifest`: `200`, `Content-Type: application/manifest+json`
- manifest: `id`, `start_url`, `scope`가 `.`이고 `display`가 `standalone`
- `/app/icon-192.png`, `/app/icon-512.png`: `200`
- `/app/service-worker.js`: `200`, `Content-Type: application/javascript`, `Cache-Control: no-cache`
- 서비스 워커에는 `install`·`activate`만 있고 `fetch` 처리와 Cache Storage 사용은 없음
- 512px 아이콘의 워드마크가 maskable 중심 안전 영역 안에 놓인 것을 원본으로 확인

검증용 컨테이너는 확인 직후 종료했다.

standalone 표시와 서비스 워커 갱신을 각각 확인해야 한다. 이 검증 전에는 Jira 업무를 완료로
전환하지 않는다.
