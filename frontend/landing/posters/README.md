# 포스터 이미지

지도 섹션의 링 타일 20칸이 이 폴더를 읽습니다.

## 파일 규칙

이름은 **두 자리 숫자**, 확장자는 아래 중 아무거나.

```
01.jpg   02.png   03.webp   ...   20.jpg
```

지원 형식: `jpg` `jpeg` `png` `webp`

- 비율은 **2:3 세로** (예: 500 × 750) 가 가장 잘 맞습니다
- 타일이 3:4 프레임이라 위아래가 살짝 잘립니다. 인물 얼굴은 가운데로
- 가로 사진을 넣으면 좌우가 크게 잘립니다

**번호가 비어 있어도 됩니다.** 03, 04가 없고 05만 있어도 05는 정상으로 들어갑니다.
없는 칸은 빈 유리 타일로 남고, 깨진 이미지 아이콘은 뜨지 않습니다.

파일을 넣은 뒤 브라우저를 새로고침하면 반영됩니다.

## TMDB 로 바꾸려면

`index.html` 상단의 두 상수만 고치면 됩니다.

```js
const POSTER_MODE = 'tmdb';
const TMDB_KEY = '여기에 API 키';
```

TMDB 평점순 상위 20편의 포스터를 받아 타일에 채웁니다.
키가 비어 있거나 요청이 실패하면 이 폴더의 로컬 파일 상태를 그대로 씁니다.

API 키는 https://www.themoviedb.org 가입 후 Settings > API 에서 발급받습니다.

> 배포할 때는 키를 프론트엔드에 두지 마세요. 백엔드에서 대신 호출하고
> 결과만 내려주는 방식으로 바꿔야 합니다.

## 이미지 출처 주의

제출물이 공개되거나 발표 자료에 들어간다면 아래는 피하는 편이 안전합니다.

- 영화, 애니메이션 캐릭터 이미지 (저작권)
- 자동차 브랜드 공식 렌더 이미지 (상표, 저작권)
- 특정 개인을 알아볼 수 있는 사진 (초상권)
- 다른 팀 프로젝트의 결과물 이미지

TMDB 포스터는 서비스 성격상 사용이 허용되며, 출처 표기를 요구합니다.
그 외에는 Unsplash, Pexels 같은 자유 이용 이미지가 무난합니다.
