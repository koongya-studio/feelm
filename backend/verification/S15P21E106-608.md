# S15P21E106-608 테스트 fixture 재사용 검증

## 측정 기준선

GitLab 성공 Job [568936](https://lab.ssafy.com/s15-bigdata-dist-sub1/S15P21E106/-/jobs/568936),
[568898](https://lab.ssafy.com/s15-bigdata-dist-sub1/S15P21E106/-/jobs/568898)의
BACKEND_TEST_TIMING 기준으로 전체 약 465초, Gradle 약 384초, test 약 267초다.
이 두 건은 테스트 수가 각각 1645/1646으로 다르므로 완료 조건의 동일 집합 3회 기준선이
아니다. 성능 목표 달성은 아직 확인되지 않았다.

JUnit은 이미 클래스 두 개를 병렬 실행한다. Gradle maxParallelForks=1은 JVM worker
수이며 테스트 전체가 직렬이라는 뜻이 아니다. 따라서 suite/lifecycle 합계를 벽시계
시간에서 그대로 빼거나 해당 합계 전체를 줄일 수 있는 시간으로 간주하지 않는다.

## 변경 범위

OttCatalogSeedMigrationTest, PopcornFlavorSeedMigrationTest,
PopcornFlavorMetadataMigrationTest가 사용하는 이전 버전 DB를 실제 Flyway SQL로
JVM당 버전별 한 번 생성한다. 원본 연결은 차단하고 호출할 때마다 독립 PostgreSQL
database를 복제한다. 각 복제본은 기존 try-with-resources로 정리되며 원본은 테스트
전용 컨테이너가 종료될 때 함께 제거된다. 운영 migration, 대상 SQL 실행, assertion,
충돌 rollback 검증, Runner 격리 및 기존 병렬 정책은 변경하지 않는다.

MigrationFixtureIsolationTest는 history 버전, 복제본의 데이터·시퀀스·후속 migration
격리 및 후속 복제본의 무오염을 실제 PostgreSQL에서 확인한다.

## 검증 상태

- Windows Java 21: compileTestJava, spotlessApply 성공.
- 전체 build: compileJava, compileTestJava, assemble, spotlessCheck 통과.
  테스트 단계는 Docker 엔진 연결 불가로 실패한다. `docker info`는
  dockerDesktopLinuxEngine named pipe 없음, Testcontainers는 Docker 환경 탐색 실패를
  보고했다. Docker Desktop 프로세스를 시작해도 엔진 연결은 복구되지 않았다.
  신규 fixture 격리 테스트와 기존 migration 테스트는 초기화 단계에서 실패하여 실제
  SQL 동작은 아직 검증되지 않았다.
  실행 결과는 1073 tests completed, 575 failed이다. 클래스 초기화 실패로 discovery된
  실행 건수가 정상 CI 1645건보다 적으며 테스트를 삭제하거나 skip한 결과가 아니다.
- 전후 같은 테스트 집합 3회 CI 측정: 미수행. 테스트 건수·오류·skip 및 cleanup 증빙과
  함께 비교해야 한다. 로컬 컴파일 성공만으로 성능·격리 통과를 판단하지 않는다.

## 남은 병목

이번 후보는 migration fixture 반복 비용을 대상으로 한다. Spring Context 시작,
계약 테스트 본문, Java 컴파일 및 Runner 준비·정리 비용은 별도로 남는다.
15% 단축 또는 390초 이하 목표가 검증될 때까지 Jira 완료로 전환하지 않는다.

## 재개 절차

Docker Desktop Linux 엔진에 `docker info`가 성공한 뒤 backend 디렉터리에서
`./gradlew build --no-daemon`을 실행한다(Windows는 `gradlew.bat`).
동일 source 기준 변경 전후 각각 3회 격리 CI 검증을 실행하여 실제 job 경과시간과
BACKEND_TEST_RESULT/TIMING을 비교한다. 컴파일 캐시가 따뜻한 로컬 재실행을
CI 성능 개선의 증거로 사용하지 않는다.
