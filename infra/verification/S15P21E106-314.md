# S15P21E106-314 검증 기록

## 장애 원인

- MR !98의 `backend-cache-status`가
  `MR_ADAPTER_HTTP_ERROR: stage=dependency_diff status=404`로 실패했다.
- 서버 root 어댑터가 GitLab Job Token으로 `merge_requests/:iid/diffs` API를 호출했고, 현재
  GitLab 환경은 이 요청을 허용하지 않아 404를 반환했다.
- cache `prepare`·`promote` 성공은 Gradle cache stage 전환 결과이며 설치된 root 어댑터
  갱신을 의미하지 않는다.
- 첫 수정본을 서버에 적용한 뒤 commit에 연결된 MR 목록 응답에 `diff_refs`가 없어
  `MR_JOB_REJECTED: Merge request diff revisions are missing or inconsistent`로 실패했다.
- 목록 API는 MR 연결 검증에 유지하고, cache status Job에서만 검증한 IID의 MR 상세 API를
  추가 조회해 `diff_refs`를 확보하도록 보완했다.
- 서버 갱신 후 `backend-cache-status`는 통과했지만 다음 `test` 단계의 `backend-mr-test`는
  GitLab Runner가 이전 단계 의존성을 Job 응답에 포함해
  `MR_JOB_REJECTED: Job services/cache/artifacts are not supported`로 거부됐다.
- `backend-mr-test.dependencies: []`를 명시해 이전 단계 artifact 다운로드와 Job 응답의
  암묵적 의존성을 차단하고, 어댑터의 fail-closed 정책은 완화하지 않았다.

## 로컬 검증

- status Job이 MR diff API를 호출하지 않고 검증된 `diff_refs.base_sha`와 정확한 HEAD SHA를
  고정 GitLab 저장소에서 인증된 Git fetch로 가져오도록 변경했다.
- NUL 구분 `git diff --name-only`, 출력 크기와 경로 수 제한, 개행 및 잘못된 UTF-8 경로 거부,
  승인된 백엔드 의존성 파일 필터를 확인했다.
- 기준·HEAD SHA 누락 및 불일치, 무관한 변경과 Git fetch 실패를 fail-closed로 검증했다.
- Git 명령행에는 Job Token이 없고 비대화형 인증, 전역·시스템 설정 차단과 redirect 거부 설정을
  별도 환경에 전달한다. Git 출력은 폐기하거나 크기를 제한한다.
- Git 실패 로그는 URL·명령 출력·토큰 없이 `dependency_git_init`, `dependency_fetch`,
  `dependency_diff` 단계만 표시한다.
- `python -I -B infra/scripts/test_ci_gitlab_job_adapter.py`: 14개 통과.
- `python -I -B -m unittest discover -s infra/scripts -p "test_ci_*.py"`: 286개 통과,
  Windows에서 Linux 전용 18개 건너뜀.
- Jira 계획 미리보기와 `git diff --check`가 통과했다.

## 서버 및 GitLab 남은 검증

- 최신 develop에서 만든 server stage로 `ci-dependency-cache-install.py --confirm-update`를 실행한다.
- 출력된 `PREVIOUS_INSTALL`, `PREVIOUS_SUDOERS`를 기록하고 MR Runner active 상태와 sudoers 구문,
  설치된 어댑터가 MR diff API를 포함하지 않는지 확인한다.
- cache가 promote된 MR !98의 동일 HEAD에서 `backend-cache-status` 통과와
  `backend-mr-test` 시작·전체 성공을 확인한다.
- 설치 또는 Runner 재시작 실패 시 이전 설치 자동 복구 결과를 확인한다.
