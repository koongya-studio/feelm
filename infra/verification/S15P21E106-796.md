## 실행 중 확인한 사항

최초 실행에서는 Kafka, Consumer Group과 HDFS 단계가 모두 `Host key verification
failed`로 실패했다. Kafka·HDFS 또는 분산 런타임 장애가 아니라 서비스 노드에서 분산
노드로 연결하는 SSH 실행 전제조건이 충족되지 않은 상태였으므로 복구 배포를 실행하지
않았다.

서비스 노드의 `known_hosts`에 분산 노드 ED25519 키를 확인·등록하고, 개인 PC의
`J15E106T.pem`을 SSH agent forwarding으로 전달했다. 이후 아래 비대화형 연결이 종료
코드 `0`임을 확인한 뒤 전체 Smoke Test를 재실행했다.

```bash
ssh -o BatchMode=yes ubuntu@172.26.0.121 true
```

재실행 결과 모든 단계가 통과했다. 따라서 이 실행에서는 어느 배포도 복구할 필요가 없다.
서버에 개인키를 복사하지 않았으며, SSH agent forwarding 세션에서만 분산 노드 인증을
사용했다.

## 남은 범위

- 이번 기록은 단일 전체 흐름 Smoke Test이며 부하·장시간 안정성 시험을 대체하지 않는다.
- 자동 롤백은 실행하지 않았다. 실패 시 보고서의 최초 실패 단계와 복구 안내를 사람이
  검토한 뒤 해당 배포 단위의 복구 절차를 수행한다.
