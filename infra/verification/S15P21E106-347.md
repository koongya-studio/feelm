## 운영 검증 체크리스트

- [ ] 분산 노드에서 `docker compose ... config`가 성공한다.
- [x] Kafka Exporter가 `unless-stopped`, read-only root filesystem, 권한 제거 상태로 기동한다.
- [x] exporter가 `127.0.0.1:9092`의 broker만 조회하고 `9308/tcp`는 분산 노드 사설 IP에만 바인딩한다.
- [ ] 방화벽이 서비스 노드 사설 IP의 `9308/tcp` 접근만 허용하고 공인망 접근을 차단한다.
  허용·차단 규칙 순서와 systemd 서비스의 `enabled`, `active`는 확인했지만 공인망 연결 실패는
  별도로 확인하지 않았다.
- [x] 서비스 노드에서 exporter `/metrics`를 조회할 수 있다.
- [x] Prometheus의 `up{job="kafka"}`와 `kafka_brokers{job="kafka"}`가 각각 `1`이다.
- [ ] Kafka Overview에 topic 처리량, partition 상태, Consumer Group·partition lag가 표시된다.
  브라우저에서 exporter `UP`, broker `1`, under-replicated partition `0`, topic partition `3`과
  `feelm.rating.v1` 처리율 패널을 확인했다. Consumer 미기동으로 lag·member 패널은 `No data`이다.
- [ ] 합성 topic·group에서 Consumer 중단 시 lag 증가, 재개 시 감소를 검증한다.
- [x] exporter 중단 시 `up=0`, 재기동 후 `up=1`로 복구된다.
- [ ] exporter 추가 전후 broker·Consumer 처리에 회귀가 없고 수집 부하가 허용 범위다.
