## 미검증과 운영 확인

- 로컬 Docker CLI/엔진이 없어 실제 이미지 빌드·컨테이너 smoke·Docker Hub Push·서버
  배포는 실행하지 않았다. 보호된 main CI에서 최초 이미지 검증과 배포 결과를 확인해야 한다.
- GitLab API 조회는 401로 실패했으나 MR 생성 전 로그인된 브라우저에서 열린 MR 8개를
  확인했다. 기존 S15P21E106-352 브랜치의 열린 MR은 없었다. Spark 관련 열린 MR
  !500(S15P21E106-720), !485(S15P21E106-711)은 별도 평가·테스트 작업이다.
- 첫 배포는 새 runtime label이 있는 코드 이미지가 먼저 성공해야 한다. 이전 코드 이미지를
  사용하는 History 전용 배포는 label 검증에서 중단된다.
- History 실패 시 기존 History 컨테이너만 복구한다. 성공한 Master·Worker를 되돌리지 않으므로
  실패 원인을 해결하고 History Job을 재시도하여 digest를 일치시킨다. 전체 Spark 코드를
  별도로 rollback했다면 History도 다시 배포한다.
- 실제 두 서버의 executor 및 HDFS 연동은 `infra/spark/ml-cluster-check.py` 운영 절차로
  검증한다. 빌드 단계 local[2] smoke는 분산 통합 검증을 대체하지 않는다.

운영 배포는 수행하지 않았다. 이 기록은 MR 제출 전 로컬 검증 결과다.
