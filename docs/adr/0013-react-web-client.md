# ADR-0013: 웹 클라이언트는 React와 Vite 기반 반응형 웹앱으로 구현한다

| 항목 | 값 |
|---|---|
| 상태 | 채택 |
| 결정일 | 2026-08-31 |
| 결정자 | 팀 확정, S15P21E106-127에서 기록 |
| 관련 | ADR-0005 대체, ADR-0009, S15P21E106-127 |

## 맥락

필름·팝콘 버킷·추천·파티처럼 상태와 상호작용이 많은 화면을 하나의 웹 클라이언트로 구현해야 한다. ADR-0005는 Vue를 선택했지만 실제 프론트엔드 기술을 React 기반 웹앱으로 변경하기로 팀에서 확정했다.

## 결정

웹 클라이언트는 React와 Vite 기반 반응형 웹앱으로 구현한다. Vite를 개발 서버와 Production Build 도구로 사용하고, 팝콘 버킷은 React에서 SVG로 렌더링한다. 인증 토큰 전달 방식은 ADR-0009를 따른다. 이 결정은 ADR-0005를 대체한다.

## 고려한 대안

| 대안 | 장점 | 단점 |
|---|---|---|
| React + Vite 반응형 웹앱 (선택) | 팀의 확정 기술과 일치, 빠른 개발 서버와 단순한 Build 구성, React 생태계 | 프론트엔드 공통 규칙과 상태 관리 방식 추가 합의 필요 |
| Vue SPA | 기존 ADR과 문서 유지 | 실제 구현 기술과 불일치 |
| 네이티브 모바일 앱 병행 | 플랫폼 기능 활용 | 1차 MVP 범위와 개발 비용 증가 |

## 결과

- **얻는 것**: 구현 기술과 문서의 일치, React 생태계와 Vite 개발·Build 환경을 활용한 필름·팝콘·파티 UI 개발
- **감수하는 것**: 기존 Vue 기준 문서와 예시를 React 기준으로 정리해야 함
- **후속 작업**: React 프로젝트 구조·상태 관리·Vite 환경변수·테스트 전략 확정, 활성 문서의 Vue 표기 제거
