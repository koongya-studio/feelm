# ADR-0005: 웹 클라이언트는 Vue로 구현한다

| 항목 | 값 |
|---|---|
| 상태 | 채택 |
| 결정일 | 2026-08 (기술 스택 확정, README 10장) |
| 결정자 | FE 담당, 팀 합의 |
| 관련 | README 5장 와이어프레임 29개 |

## 맥락

필름·팝콘 버킷·파티 UI 등 상태가 많은 화면 29개를 구현해야 하며, 팀 FE 인력의 주 프레임워크가 Vue다. 초기 범위는 웹 단일 클라이언트다.

## 결정

Vue(SPA)로 구현한다. 인증 토큰 전달 방식은 ADR-0009에 따른다.

## 고려한 대안

| 대안 | 장점 | 단점 |
|---|---|---|
| Vue (선택) | 팀 숙련도, 단일 클라이언트 | 모바일 앱 확장 시 재작성 |
| React | 생태계 | 팀 숙련도 낮음 |
| Vue + 모바일 앱 병행 | 네이티브 경험 | 1차 MVP 범위 초과 |

## 결과

- **얻는 것**: 빠른 화면 구현
- **감수하는 것**: 웹 전용 가정이 인증 방식(httpOnly 쿠키)에 반영됨 — 모바일 앱 추가 시 ADR-0009 재검토
- **후속 작업**: 화면 ↔ API 매핑(API 명세 화면 열) 기준 구현
