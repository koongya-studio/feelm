# ADR-0003: 서비스 백엔드는 Spring Boot로 구현한다

| 항목 | 값 |
|---|---|
| 상태 | 채택 |
| 결정일 | 2026-08 (기술 스택 확정, README 10장) |
| 결정자 | BE 담당, 팀 합의 |
| 관련 | NFR-04, NFR-05, NFR-07, docs/api |

## 맥락

회원·영화·평가·파티·OTT 등 서비스 API와 트랜잭션 처리(평가 저장 시 프레임·팝콘 동시 생성, NFR-06)를 담당하는 서버가 필요하다. 팀 BE 인력의 주 언어가 Java다.

## 결정

Spring Boot로 REST API 서버를 구현한다. 인증은 JWT(ADR-0009), 영속성은 Spring Data JPA + PostgreSQL(ADR-0004)로 한다.

## 고려한 대안

| 대안 | 장점 | 단점 |
|---|---|---|
| Spring Boot (선택) | 팀 숙련도, 트랜잭션·보안·검증 생태계, SSAFY 표준 | 추천 로직이 Python일 때 언어 경계 발생 |
| FastAPI 단일 백엔드 | 추천과 같은 언어 | BE 인력 언어 불일치, 트랜잭션·ORM 성숙도 |
| Node.js | FE와 언어 통일 | 팀 숙련도 부족 |

## 결과

- **얻는 것**: 안정적인 트랜잭션·인증 처리, 팀 생산성
- **감수하는 것**: 추천 계산 위치 결정(ADR-0012)에 따라 내부 API 경계 필요
- **후속 작업**: 공통 오류 응답·페이지네이션 규약 구현(API-000)
