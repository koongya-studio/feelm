# ADR-0025: 개인·파티 추천의 점수 모델을 v26 GBT로 전환한다

| 항목 | 값 |
|---|---|
| 상태 | 제안 — 확정 연구·병합 구현의 소급 기록, ADR 채택 리뷰 대기 |
| 결정일 | ADR 채택일 미정. 모델 선택 승인 기록: 2026-09-23 |
| 결정자 | 모델 선택: 사용자 승인(S15P21E106-625). ADR 채택: 팀 리뷰 대기 |
| 관련 | S15P21E106-838, 625·626·627·742·747·829·644, FR-10·FR-12·FR-22, API-045·API-058, ADR-0002·ADR-0017 |

## 맥락

ADR-0002는 ALS+콘텐츠 Hybrid와 서비스 사용자 Fold-in을 선택했고, ADR-0017은 개인
계산을 Python Consumer, 전역 집계를 Spark Structured Streaming으로 분리했다.
이후 [625 연구 마감](../../pipeline/docs/gbt-transition/README.md)에서 사용자가 v26을
채택했고, 2026-09-24 develop에 공통 scorer·개인·파티·내부 입력 계약·이미지 연결이 반영됐다.
2026-09-25 사용자 확인으로 GBT 서버 적용도 완료된 상태를 기록한다.
현재 상태를 설명하는 [v26 안내](../../pipeline/docs/gbt-v26/README.md)와 기존 ADR 사이의 차이를 소급 기록한다.

MovieLens factor가 없는 영화에도 검증된 metadata 특징이 있으면 점수를 계산하고,
서비스의 전체 유효 이력과 강한 개인 연결·TMDB/KOBIS 근거를 동일 모델에 넣기 위한 선택이다.
오프라인 평가가 모든 기준선보다 우수하거나 실제 한국 사용자·파티 만족도를 입증했다는 결정은 아니다.

## 결정

소급 기록할 내용은 개인 TASTE와 파티 구성원 점수에 같은 v26 GBT를 사용하고,
기존 Python Consumer·Kafka·Redis·Spring 서빙 경계를 유지하는 것이다.
새 모델이나 API/DB/배포 정책을 추가 제안하지 않는다.

1. `gbt-v26-top2-raw`와 71열 변환을 사용한다. 출력은 추천 정책 점수이며 예상 별점이 아니다.
   학습 목표의 0.5 억제와 2,294표 기준을 서빙 후처리 필터로 다시 적용하지 않는다.
2. 개인은 지원 개봉 전체 카탈로그를 전체 유효 이력으로 점수화한다. 실제 평가 우선,
   미평가 관심없음의 계산상1.0과 현재 모드별 제외를 유지한다. 입력0개는 현재627의 인기순 공급이다.
3. 파티는 동일 세대의 불변 입력을 사용해 공통 후보를 구성원별 GBT로 재점수화한다.
   K>0 구성원별 midrank fit의 동등 평균과 최솟값·표준편차·movieId 동점 규칙을 사용한다.
4. 활성 GBT 경로는 ALS fold-in·Item Factor·ALS+콘텐츠 혼합을 호출하지 않는다.
   기존 ALS 연구·분산 성능 실험·전환 호환 코드는 역사 및 복구 경계를 설명하는 자료로 보존한다.
5. DISCOVERY의 그룹·대중성 공급, pgvector 유사 영화, Spark의 전역 인기 집계는 별도 책임이다.
   모델·catalog·매핑·코드·runtime은 같은 불변 servingRevision으로 검증한다.

채택 시 ADR-0002의 개인·파티 모델 선택을 대체하고, ADR-0017의 Fold-in/vector와 모델별
계산 설명을 본 결정으로 대체한다. Python 사용자 계산/Spark 전역 집계의 책임 분리는 유지한다.
이번 제안에서는 두 채택 ADR의 상태·본문을 변경하지 않는다. 세부 payload·제외·세트 조립은
이미 반영된 [스트리밍 계약](../api/streaming-contract.md)과 [모델 계약](../../pipeline/contracts/gbt-model-artifacts.md)이 기준이다.

## 고려한 대안

| 대안 | 판단 |
|---|---|
| v26 GBT 공통 scorer | 사용자 승인·개인/파티 구현 반영. 학습/서빙 특징과 버전 일치가 필요 |
| 기존 ALS+콘텐츠 | 연구 비교·이전 실행 경로를 보존하나 활성 GBT에서 자동 혼합·fallback하지 않음 |
| FM 및 과거230/245열 모델 | 연구 이력으로 보존. 최종71열 번들을 대체하지 않음 |
| GBT 뒤 공개근거 품질/언어 필터 | 별도 품질 필터 없이 raw 순위를 채택했고, 제목 감점668은 미진행 종료 |

## 결과

- **얻는 것**: 개인 전체 후보와 파티 subset이 같은 모델·특징을 사용한다. 전체 유효 이력을
  사용하고 모델/입력 버전을 통해 요청의 점수를 추적할 수 있다.
- **감수하는 것**: 영화 매핑·metadata 지원 범위, 학습 목표 편향, 전체 카탈로그 계산 비용과
  입력 snapshot 보존을 관리해야 한다. 상대 fit은 파티의 절대 만족도 보장이 아니다.
- **현재 적용**: GBT는 서버 적용까지 완료됐다.483·628·668의 미진행 종료는 각각의 제외된
  작업 범위를 나타내며 서버 적용 완료와 구분한다.
- **후속 작업**: 팀 리뷰에서 이 ADR 채택과 기존 ADR의 대체 상태를 확정한다.
