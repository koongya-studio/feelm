# ADR-0002: 추천 모델은 ALS + 콘텐츠 기반 Hybrid로 구성한다

| 항목 | 값 |
|---|---|
| 상태 | 채택 |
| 결정일 | 2026-08 (기술 스택 확정, README 8·10장) |
| 결정자 | AI 담당, 팀 합의 |
| 관련 | FR-10, FR-11, FR-12, README 8장 |

## 맥락

취향 맞춤(FR-10)·취향 발견(FR-12)·유사 영화(FR-11) 세 종류 추천이 필요하다. 협업 필터링만으로는 콘텐츠 유사성과 콜드 스타트를 다루기 어렵고, 콘텐츠 기반만으로는 개인화가 약하다.

## 결정

MovieLens 평점으로 ALS를 학습해 사용자·영화 잠재 벡터를 만들고, TMDb 메타데이터(장르·태그·줄거리·감독·배우)로 콘텐츠 기반 유사도를 계산해 두 결과를 결합한다. 서비스 사용자는 평가 기반 Fold-in으로 벡터를 생성한다. 파티 추천 집계식(Average / Least Misery / 개선식)은 비교 실험 후 확정한다.

## 고려한 대안

| 대안 | 장점 | 단점 |
|---|---|---|
| ALS + 콘텐츠 Hybrid (선택) | 개인화와 콜드 스타트 보완, 유사 추천 재사용 | 두 모델 유지, 결합 가중치 튜닝 |
| ALS 단독 | 단순 | 신규 사용자·신규 영화 처리 약함, 유사 영화 추천 불가 |
| 딥러닝 시퀀스 모델 | 높은 정확도 가능 | 데이터·시간·설명 가능성(XAI) 확보 어려움 |

## 결과

- **얻는 것**: NDCG@10·Recall@10 검증 가능한 표준 구조, XAI 근거 추출 용이
- **감수하는 것**: 결합 가중치·발견 추천 임계치 튜닝 비용, 콘텐츠 임베딩 방식에 따라 Python 전용 라이브러리 의존(ADR-0012 참조)
- **후속 작업**: 파티 집계식 비교 실험(FR-22 검증 항목), 취향 발견 임계치 확정(API-041)
